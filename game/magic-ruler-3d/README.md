# Magic Ruler 3D

一个不依赖第三方运行时的浏览器版魔尺空间折叠益智游戏，共 9 个关卡。

## 启动

在仓库根目录执行：

```bash
python3 -m http.server 8080 --directory game/magic-ruler-3d
```

然后打开 <http://localhost:8080>。

也可以直接打开 `index.html`；使用本地静态服务器时体验最稳定。

## 操作

- 拖动舞台：旋转 3D 视角
- 鼠标滚轮：缩放
- 点击圆环：选择关节
- `Q` / `←`：逆时针旋转选中关节
- `E` / `→`：顺时针旋转选中关节
- `R`：重置当前关卡
- `H`：自动校准一个关节（会计入提示次数）

青色实体是当前魔尺，紫色虚线是目标形状。所有关节与目标一致后即可过关；完成记录保存在浏览器本地存储中。
