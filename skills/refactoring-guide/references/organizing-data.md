# 组织数据 (Organizing Data)

改善数据组织方式的重构技术。

---

## 自封装字段 (Self Encapsulate Field)

**问题：** 直接访问私有字段。

**解决方案：** 为字段创建 getter 和 setter，仅通过这些访问器访问字段。

---

## 以对象取代数据值 (Replace Data Value with Object)

**问题：** 有一个数据项需要额外的行为。

**解决方案：** 将数据项变成一个对象。

---

## 将值对象改为引用对象 (Change Value to Reference)

**问题：** 有一个在对象之间共享的类的多个实例。

**解决方案：** 将相同对象用于所有实例。

---

## 将引用对象改为值对象 (Change Reference to Value)

**问题：** 引用对象很小且不可变。

**解决方案：** 复制对象。

---

## 以对象取代数组 (Replace Array with Object)

**问题：** 数组包含不同的东西。

**解决方案：** 用一个对象替换数组，该对象的字段对应数组的元素。

---

## 复制被监视数据 (Duplicate Observed Data)

**问题：** 领域数据在 GUI 控件中展示。

**解决方案：** 将领域数据复制到一个单独的对象中，该对象与界面同步。

---

## 以字面常量取代魔法数 (Replace Magic Number with Symbolic Constant)

**问题：** 代码中有一个有特定含义的字面数字。

**解决方案：** 用命名常量替换这个数字。

---

## 封装字段 (Encapsulate Field)

**问题：** 有一个公有字段。

**解决方案：** 将字段设为私有，并创建访问函数。

---

## 封装集合 (Encapsulate Collection)

**问题：** 有一个返回集合的函数。

**解决方案：** 让函数返回集合的只读视图，并添加用于添加/移除元素的函数。

---

## 以类取代类型码 (Replace Type Code with Class)

**问题：** 类有一个包含类型码的字段——不影响行为的枚举。

**解决方案：** 为类型码创建一个新类，用新类的实例替换类型码。

---

## 以子类取代类型码 (Replace Type Code with Subclasses)

**问题：** 类有一个包含类型码的字段——影响行为的枚举。

**解决方案：** 为每个类型码值创建一个子类，用多态替换条件逻辑。

---

## 以State/Strategy取代类型码 (Replace Type Code with State/Strategy)

**问题：** 类有一个包含类型码的字段——影响行为的枚举，但不能使用继承。

**解决方案：** 用状态对象替换类型码。

---

## 以字段取代子类 (Replace Subclass with Fields)

**问题：** 各个子类之间的唯一区别是它们的"常量"函数的返回值。

**解决方案：** 让函数在超类中返回这些字段值，然后删除子类。
