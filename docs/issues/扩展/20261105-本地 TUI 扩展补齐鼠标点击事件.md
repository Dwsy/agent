# Issue: 本地 TUI 扩展补齐鼠标点击事件

## Goal

自绘列表/菜单组件支持鼠标左键点击选中并执行对应动作，行为与 pi-tui 内置 `SelectList` / `SettingsList` 一致。

## 背景/问题

上一轮只补了 wheel，明确暂缓 click 命中测试。用户现要求补齐。pi-tui 内置组件的既定语义是：`press` 命中行即选中并请求焦点，`click` 命中行即选中并触发该行的确认动作（`onSelect` / `activateItem`）。自定义扩展必须沿用该语义，否则同一会话里点击行为不一致。

## 统一契约

```text
wheel             -> 已有逻辑（上一轮）
press + left      -> 命中行 ? 选中该行 + { handled: true, focus: true } : undefined
click + left      -> 命中行 ? 选中该行 + 执行该行 Enter/Space 动作 + { handled: true } : undefined
其它事件/按钮      -> undefined（交回渲染器兜底）
```

- **行命中表**：每个组件在 `render()` 时记录 `rowMap: number[]`，索引为渲染行 `y`，值为对应 item index，`-1` 表示该行不可选（表头、分组头、空行）。避免重复计算 header 偏移/滚动窗口/分组头。
- **press/click 一致性**：press 时记录 `pressedIndex`，click 优先使用它（与内置组件一样防止按下后拖到别行误触发）。
- **双栏**：仅 `event.x < splitX` 的左栏行可点；右栏详情区返回 `undefined`。
- **wrapper 不改**：上一轮已转发 `handleMouse`，内置 `SelectList` / `SettingsList` / `Input` / `Editor` 自带点击处理。
- **纯文本 overlay 不改**：PromptViewer、RoleMemoryViewerComponent、MarkdownOverlay 没有可点控件。

## 验收标准 (Acceptance Criteria)

- [ ] WHEN 左键 press 落在可选项行，系统 SHALL 选中该项并返回 `focus: true`
- [ ] WHEN 左键 click 落在可选项行，系统 SHALL 执行该行的键盘确认动作
- [ ] WHEN 点击落在表头/空行/右栏详情区，系统 SHALL 返回 `undefined`
- [ ] WHEN 事件为右键/中键/move/drag/release，系统 SHALL 返回 `undefined`
- [ ] 所有 wheel 与键盘行为保持不变

## 关键决策

| 决策 | 理由 |
|------|------|
| 沿用内置 press 选中 / click 确认 | 与 Pi 全局交互一致；键盘 ↑↓ + Enter 一一对应 |
| 用 render 期 rowMap 做命中 | 自动与滚动窗口、分组头、表头对齐，避免每个组件重算几何 |
| 不做 overlay 空白区点击关闭 | Esc/q 已覆盖；点击关闭易误触且无视觉 affordance |
| `pi-fzf` click 语义为切换开关（Space）而非 Enter 保存 | Enter 会保存全部并关闭，单击某一项直接保存全部不符合直觉 |

## 遇到的错误

| 日期 | 错误 | 解决方案 |
|------|------|---------|
| 2026-11-05 | `usage-extension` wrapper 在组件输出前拼 3 行边框，`event.y` 直接传给 UsageComponent 会整体错位 | render 时记录 `headerRows`，转发时 `y: event.y - headerRows` |
| 2026-11-05 | 契约测试把「`event.type !== "wheel"`」写死，子代理改成 `=== "wheel" &&` 后误报 | 测试正则同时接受两种写法；定义计数正则改为行首匹配以排除注释 |
| 2026-11-05 | 3 个并行子代理在编辑完成后陷入收尾循环（14 分钟 / 40 turns） | 父级确认文件落盘且 mtime 稳定后终止子代理，亲自完成复核与验证 |

## 已知限制（未在本轮修改，建议单独一轮）

上一轮把 `handleMouse` 转发给 pi-tui 内置组件的 wrapper，转发时未平移坐标：

| 文件 | 偏移来源 |
|---|---|
| `pi-custom-compaction/src/ui.ts`（2 处） | 第 1 处前面有 `Search model:` + Input + 空行；第 2 处 `framePanel` 加 1 行上边框 + 1 列左边框 |
| `pi-rtk-optimizer/src/zellij-modal.ts` / `config-modal.ts` | `renderFrame` 的 `contentStartLine` + 左右 padding |

偏移会让内置 `SelectList` / `SettingsList` 的 `event.y` 命中错误行。本轮只修了 `usage-extension`（因为它的 `UsageComponent` 是本轮新加 rowMap 的自绘组件，必须对齐）。这些 wrapper 需要统一的「转发时平移 y/x」契约，并配合真实交互验证。
