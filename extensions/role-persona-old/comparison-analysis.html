像《攻壳机动队》的电子脑——专注于构建 AI 的人格连续性和记忆生命周期管理。

6优劣势分析

Role Persona 独特优势

Pending 验证层 压缩搭便车 遗忘曲线 标签关联网络 混合搜索 RRF 零外部依赖 人类可读 Markdown

核心创新在于记忆生命周期管理——不只是存储，而是通过 pending 验证、遗忘曲线、标签关联等机制主动管理记忆的价值和衰减。

Claude Code 独特优势

Team Memory 完整工具生态 MCP 协议 权限系统 Agent 编排 插件市场 React TUI

核心优势在于生态完整性——从工具到插件到团队协作，构建了一个完整的 AI 编程助手平台，记忆只是其中一个模块。
