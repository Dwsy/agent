5-Phase Workflow

强制性工作流，
不让 AI 跳过关键步骤

每个任务都必须经历 5 个阶段，防止 AI 在不完整理解的情况下生成代码。

PHASE 01
上下文检索
定位相关代码文件、测试、用例，构建完整上下文图谱
→
PHASE 02
深度分析
理解需求本质，识别边界情况，评估技术可行性
→
PHASE 03
原型设计
快速验证方案方向，收集早期反馈
→
PHASE 04
实现
生成生产级代码，遵循项目规范与风格
→
PHASE 05
审计
安全审查、性能分析、回归测试、文档补全

Core Capabilities

不只是聊天机器人

每个功能都经过生产环境验证，为企业级使用场景设计。

多模型编排

同时调度 Claude、Gemini 和 Codex，根据任务类型智能路由到最合适的模型。

沙箱安全

ExecGuard 执行守卫、SSRF 防护、allowlist 授权、exec-backlist 黑名单，防止误操作。

定时任务

内置 Cron Engine，支持 announce/silent 投递模式、并发守卫、错误退避策略。

角色人格隔离

role-persona 支持按角色隔离记忆、向量检索和人格配置，不同场景独立运行。

并发背压控制

async-limit 并发限制器 + 优先级消息队列，防止网关在高负载下崩溃。

会话持久化

Session Store 跨会话保持上下文，Transcript Logger 记录完整对话历史。

Clean Architecture v4.0

4 层清晰架构，
每一层职责分明

Domain → Application → Infrastructure → Interface，依赖方向严格单向。700+ 测试用例保障架构契约不被破坏。

Domain — 纯业务逻辑，无外部依赖
Application — 用例编排，定义端口接口
Infrastructure — 外部系统实现
Interface — 适配层（HTTP/WS/Plugins）
